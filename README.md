# Poker Tracker

A phone-first web app for our friends' poker nights. It **only records** — no money is handled.

- Players, game nights, buy-ins and re-buys (with exact times), cash-outs
- Win/loss per night, a check that buy-ins match cash-outs, and settle-up with the fewest transfers (with paid ticks)
- Live view on everyone's phone, session notes, fun awards, timeline
- Leaderboard, per-player stats and trend chart
- CSV export, WhatsApp share, dark mode (follows the phone)

**Who can do what:** anyone with the link can view. Only signed-in bankers can add or change data. Only the owner can add or remove bankers.

Built with plain HTML/CSS/JavaScript on GitHub Pages, with a free Supabase database.
